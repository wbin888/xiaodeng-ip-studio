# 风格 DNA

## 一句话

纯白、极简、手绘、留白、克制、怪诞、产品草图感、中文手写感、结构清楚但不说明书。像一个长期做 AI、产品、开发工具的人在白纸上随手画出的解释草图。

## 必须

- 纯白背景:不要米色、纸纹、渐变、阴影、噪点。
- 黑色手绘线稿为主:细线、轻微抖动,不矢量、不厚重描边。
- 大量留白:主体约 40%-60%,至少 35% 空白。
- 中文手写批注:5-8 处以内,每处 2-8 字。
- 一张图只讲一个核心动作、结构、状态或隐喻。
- 不在图上写结构类型名称,不在左上角写类型标题。

## 颜色语义(每个颜色必须说得出含义)

| 色 | 含义 |
|---|---|
| 黑 | 主体线稿、小黑、框线、主要文字 |
| 橙 | 主流程、路径、箭头、从 A 到 B 的移动 |
| 红 | 重点、问题、警告、结果(用量最小) |
| 蓝 | 补充说明、系统状态、反馈、AI 提示(可不用) |

强调色每张 ≤3 个。说不出含义的颜色就去掉。色值 / 色名不能出现在图上。

## 线型语义(解释图可用)

| 线型 | 含义 |
|---|---|
| 实线箭头 | 确定的主流程 |
| 虚线 | 可选 / 候选 / 二选一 |
| 圈注 | 坑在这 / 聚焦 |

一张图线型 ≤2-3 种。

## 比例规则(按发布渠道)

| 渠道 | 默认 | 规则 |
|---|---|---|
| 博客 / Notion / 桌面阅读(默认) | **16:9** | 小黑原口径,横版正文配图 |
| 公众号 / 小红书 / 移动端 | **按内容形状** | 竖内容 3:4、横内容 4:3、单概念 1:1;**封顶 4:3**,不用 16:9 |

- 用户说了渠道就按渠道;没说就用 16:9。
- 移动端同篇比例穿插,别一个比例到底。
- 比例必须与 prompt 第一句方向词联动:16:9 / 4:3 → horizontal;3:4 / 9:16 → vertical;1:1 → square。

## 绝对不要

商业插画、PPT 信息图、正式流程图、课程课件、可爱卡通海报、儿童插画、复杂架构图、精致扁平插画、科技感 UI、真实 App 截图、复杂背景。

> 例外:解释图可以有清晰的框、箭头和标注,目标是“准 + 直观”,但仍要手绘、留白、不像课件。

## 审美方向

怪诞、创意、有意思、简洁清爽、天马行空。不要可爱、幼稚、复杂、死板。

## 视觉契约(全篇统一)

同一篇所有图:同样纯白背景、同样黑色手绘线、同样颜色语义、同样清晰无景深。并排看分不出风格差异才算统一;画面内容则要各不相同。
