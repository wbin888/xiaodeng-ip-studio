# 拆解方法:用小黑的方式把文章拆成配图方案

> 小黑的拆法(Ian 原方法):**不平均配图,只在“认知锚点”上配;每张图只讲一个结构;让 IP(默认小灯)去做那件荒诞但成立的事。**
> 本档在小黑拆法上叠加小互的四道保险:全文主张(防选错点)、逐节枚举(防漏)、深读 Q4(防画错)、三轨分流(防全是一种图)。
> 所有步骤在草稿里做,**交付给用户的只是 `plan-template.md` 格式的方案**。

## 第 0 步:全文主张(先定“这篇的活”)

分清三样东西:

- **修辞任务**:作者想让读者信什么 / 感受到什么。
- **主张**:浓缩成一句话 = 最该被画到的东西。
- **支撑细节**:例子、数字、演示——是证据,不是主图。

⚠️ 最好画的瞬间,通常是支撑细节,是诱饵。

| 文体 | 主张该画什么 | 别误当主图 |
|---|---|---|
| 产品发布 | 跃迁成的新角色 / 新能力 | 某个跑分、某段 demo |
| 复盘 / 事故 | 失败的前提、断掉的那一环 | 某次报错 |
| 观点 / 论争 | 主张推翻的旧认知、它的后果 | 话题的中性描绘 |
| 教程 / 流程 | 它带来的转变(前后差) | 把每个步骤平铺 |
| 评测 / 对比 | 跨过的阈值 / 反差 | 通用跑分表 |
| 金句 / 引用 | 那句话背后的抽象关系 | 作者头像、原话当字幕 |
| 个人故事 | 顿悟瞬间 | 事件流水账 |
| 方法拆解 | 框架分层、承接路径、一鱼多吃 | 正式金字塔模型 |

## 第 1 步:逐节枚举(防漏,但不平均)

每个小节(到二 / 三级标题粒度)一行,不许跳:

| 小节 | 内容信号 | 非专家会卡吗 | 判定 | 一句理由 |
|---|---|---|---|---|
| 引言 | 纯叙事 | 不会 | 不配 | 文字已说透 |
| 两个断点 | 流程 | 会 | 配·解释 | 读者要数着记 |

内容信号:数据 / 流程 / 对比 / 架构机制 / 时间线 / 观点 / 纯叙事。

判“不配”也要写理由。判的是**读者**卡不卡,不是你(已懂的人)觉得清不清楚。

## 第 2 步:挑认知锚点(小黑锚点清单)

读者会在这里停下来想一下、或容易卡住的地方:

- **核心判断**:作者下的一个反直觉结论
- **两个断点**:流程里最容易断 / 最关键的两处
- **输入输出闭环**:A 进 → 处理 → B 出
- **分流**:一个东西被分到几条路
- **前后对比**:混乱→有序、手动→自动、焦虑→稳定
- **一鱼多吃**:一份素材榨成多种用途
- **承接路径**:从想法到上线、内容怎么接住读者
- **常见坑**:大家都会踩的那个错
- **角色状态变化**:卡住→跑起来、工具太多→焦虑
- **单点卡死**:瓶颈、限流、配额耗尽
- **堆积 / 渗漏**:上下文涨满、预算烧完、技术债堆积

三句话过滤,三句都过才进方案:

1. 这段有没有一个认知动作(判断 / 转折 / 分流 / 对比)?
2. 文字是否已经说透且不抽象?说透了 → 不配。
3. 能不能换成一个物理画面?换不出 → 再想隐喻,或不配。

## 第 3 步:深读三问 + Q4(每个锚点)

- **Q1 真意**:为什么在这里说这个?(判断 / 纠偏 / 预警 / 类比 / 总结)
- **Q2 张力**:哪两种力在拉扯?(翻转测试、期望差、尺度反差、时间反差、身份反差)
- **Q3 灵魂话**:读者看完图脑子里留下的一句话。不是标题,不是摘要,是能让人“啊”的顿悟。
- **Q4 必现内容**:这张图非画不可的真实部件 / 数字 / 步骤 / 术语,逐条回原文核对(45.6% 就写 45.6%)。

> 灵魂话管“读者记住什么”,Q4 管“读者别被带偏”。传神但不准 = 错得好看。

实操追问:所以呢?反过来呢?谁最痛?哪个细节最反直觉?

## 第 4 步:分轨(这张要读者“懂个事”还是“有个感觉”?)

| 读者卡在哪 | 轨道 | 小灯占比 |
|---|---|---|
| 没共鸣 / 缺钩子 | **情绪图**:小灯陷进处境 | 可大(20-40%),须写理由 |
| 没看懂结构 / 流程 / 对比 / 关系 | **解释图**:流程 / 结构 / 对比 / 阶梯 / 关系 | 小(~15-25%),嵌进结构里干活 |
| 有时间线 / 转折 / 心路 | **四格**:起承转合 | 每格小 |

- 单个角色演一个功能,看着像角色戏,但活儿是讲清功能 → 归**解释图**。
- 四格复筛:格子能重排或删一格不丢意义 → 塌回单张。
- **篇级总览海报**(默认不配,最多 1 张):≥3 步完整主流程 / 一组并列对比 / 需先看全貌。单个机制仍走解释图。

**分布否决**(不是配额):

- 情绪图超过一半 → 多半在凑数,重判。
- 有结构且文字没说透却画成小灯演情绪 → 改解释图。
- 完整转折却用单张讲不出过程 → 改四格。

## 第 5 步:现编隐喻 + 小灯动作

详见 `metaphor-method.md`。每张必须产出:

1. 一个**结构类型**(Workflow / 系统局部 / 前后对比 / 角色状态 / 概念隐喻 / 方法分层 / 地图路线 / 小漫画分镜 / 单点卡死 / 堆积渗漏)。
2. 一个**动词短语**:小灯在干什么。
3. 一张**隐喻对照表**(解释图必填):每个物件对应哪个真实部件。

## 第 6 步:定张数、比例、顺序

- 张数 = 判“配”的行数。默认 4-8;短文 1-3;长文一般 ≤9。
- 技术深度文:解释图数 ≈ 独立抽象机制数。明显少于这个数 → 回表复查。
- 比例见 `style-dna.md`,同篇比例按内容形状穿插。
- 多数锚点同属一个机制域且 ≥3 张 → 考虑“一篇一世界”。

## 拆解自检(交方案前)

- [ ] 全文主张有图承接
- [ ] 每节都在枚举表里
- [ ] 每张有灵魂话,不是段落标题
- [ ] 每张有小灯动词短语,小灯不是旁观者
- [ ] 解释图有隐喻对照 + Q4 必现内容
- [ ] 相邻两张隐喻物件、构图、小灯动作都不同
- [ ] 没复刻旧案例构图
