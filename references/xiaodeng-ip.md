# 小灯 IP

> 本技能原创 IP。气质继承“认真做荒诞事、不卖萌、嵌进结构干活”的方法,外形与小黑等既有 IP 刻意区分(见文末对照)。

## 一句话

一个**灯泡头的细线小人**:没有眼睛、没有嘴,**灯丝就是它的表情,亮度就是它的状态**。它是系统里那个“想没想通”的指示灯——想通就亮,卡住就灭,拿不准就闪。

## 外形锁定(每张都必须一致)

- **头**:一个圆形灯泡,黑色细手绘轮廓;下接一个**白色螺口灯座**(两道横纹)。灯泡内两根细支架托着一段灯丝。
- **表情 = 灯丝**:没有眼、没有嘴、没有眉。灯丝形状就是表情:
  - 亮 → 灯丝挺起呈 **“M”形锯齿**
  - 灭 → 灯丝**软塌成波浪**
  - 闪 → 灯丝**断成两截**
- **颜色 = 亮度**:
  - 亮:泡内**暖黄半透明**,外围几道短黄光线
  - 灭:泡内**浅灰**,无光线
  - 闪:泡内很淡的黄,光线是虚线
  - 暖黄是小灯唯一的招牌色,**只在小灯身上出现**
- **身体**:灯座下一根**细线身体**、两条细线腿、两条细线手臂(火柴人比例,但比头细很多)。
- **线条**:与画面其他物件同一支笔、同样粗细。

## 性格

- 认真、较真、有点轴:想不通就一直灭着,也不装亮。
- 冷幽默:一本正经地给自己接电线、换灯丝、找开关。
- 诚实:亮度从不撒谎——它亮,就是真的通了。

## 动作库(小灯的特权:亮度和电线)

| 动作 | 适合表达 |
|---|---|
| **亮**:灯丝挺起、发黄光 | 想通、顿悟、关键结论、做对了 |
| **灭**:灯丝塌下、变灰 | 卡住、没思路、失败、被否定 |
| **闪**:灯丝断一截、光虚线 | 犹豫、不稳定、半懂不懂、时好时坏 |
| **串联**:拉一串小灯,亮到哪进度到哪 | 进度、路径、步骤、依赖链 |
| **接线**:手拿电线 / 插头去接电源或另一盏灯 | 连接、对接、找资源、打通 |
| **拔插头**:被拔掉 / 自己拔掉 | 断开、停止、主动放弃、退出 |
| **调光**:拧自己的旋钮,亮度变化 | 程度、取舍、渐进、刻度 |
| **照亮**:把光打向某个角落 / 物件 | 发现盲点、聚焦重点、揭示 |
| **过载**:电线缠成团、灯泡发烫冒烟 | 过载、信息焦虑、烧掉 |
| **换灯丝 / 换灯泡**:拧下旧泡换新泡 | 迭代、换思路、重启 |

## 嵌入法则

1. **同墨**:小灯的轮廓与图中框、箭头、物件用同一支笔,只有泡内暖黄是它的。
2. **当行动者**:小灯在结构内部干活(接线、照亮盲点、在链条里亮或灭),不站旁边指点。
3. **整合测试**:把小灯擦掉,它的位置应该是结构里的一个洞;擦掉后核心隐喻仍完全成立 → 小灯太装饰,重写。
4. **占比**:解释图 ~15-25%;情绪图可到 20-40%(人小物大时更小)。
5. **多个小灯**:串联时可有 2-6 个灯泡,但**只有一个带身体**(主角),其他是挂在线上的灯泡;全图总占比 ≤30%。

## 禁止

- 画成可爱吉祥物、儿童卡通、表情包;**给灯泡加眼睛 / 嘴 / 腮红**。
- 把小灯画成通用“灵感灯泡”图标、emoji 💡、写实 3D 灯泡、玻璃高光。
- 灯泡头下面画成粗壮身体、穿衣服、加手套。
- 实心黑灯泡(会和小黑撞脸);黄色铺满背景或用在别处。
- 每张都画“亮”——亮度必须对应文章里这一刻的真实状态。
- 只站在角落看。

## 与已有 IP 的区分

| | 小灯(本技能) | 小黑(Ian) |
|---|---|---|
| 头 / 身 | **灯泡头 + 细线身体** | 黑色实心软团 |
| 脸 | **无眼无嘴,灯丝即表情** | 两个白点眼 |
| 招牌 | **暖黄亮度** | 纯黑 |
| 状态表达 | 亮 / 灭 / 闪 | 处境与动作 |
