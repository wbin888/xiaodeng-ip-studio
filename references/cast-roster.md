# 角色总表(38 个):选角速查

选角时读这一页。挑角色、配双人或三人组合,都先在这里定好,再去读对应的角色包。

- **来源**:有两类。
  - 「内置」是本仓库的 7 个内置原创角色(小煤球为默认),开箱即用。
  - 「小互」是小互 IP Studio 的 31 个角色。它们的形象与画风 © 小互。仓库的 `cast-xiaohu/` 已附带全部角色包和 1024px 参考图(按其 MIT + NOTICE 转载),开箱即用;用 `cast list` 和 `cast show <名>` 查看。总览图:`assets/xiaohu-cast-overview.png`。
- **肢体**:分三档。
  - **主动**:有手,能拉、递、插、写。
  - **半主动**:只有腿或身体,能夹、钩、顶、跑。
  - **被动**:无肢,只能被压、被推、堵住、发光,或改变自身状态。
- **招牌色**:每个角色唯一允许的彩色。同框时招牌色不能撞,撞色规则见 `ensemble.md`。
- **适合当**:主角(主线动作)、搭档(第二视角或对照方)、龙套(一张图里点一下,不能整篇反复出现)。

## 推荐组合

| 组合 | 适合的文章 | 分工 |
|---|---|---|
| 小煤球 + 小针 | 工具链、工作流、系统集成 | 小针串起各环节,小煤球在终点扑住最后一环,小芽开花 |

| 小煤球 + 小墨 | 认知转变、旧观念 vs 新方法 | 小墨是晕开的旧习惯,小煤球一爪把它推下桌,换上新判断 |
| 小煤球 + 替替 | AI 协作、人机分工 | 替替做重复活,小煤球做判断 |
| 小煤球 + 牛马 | 提效、自动化、职场 | 牛马扛活,小煤球理顺毛线把流程接上后,牛马终于坐下 |
| 小灯 + 小针 | 决策链、系统接通 | 小针串起各环节,小灯在终点亮起 |
| 小南瓜 + 小方 | 长期积累、复利、收获 | 小南瓜沿藤蔓一个个结果,小方把收成装箱 |
| 小方 + 小针 | 收集 → 分发、信息流 | 小方吞进来,小针分出去 |
| 小煤球 + 丁零 + 牛马 | 截止日期压力、项目管理 | 丁零催,牛马扛,小煤球扑住关键路径 |
