# 小煤球 IP

> 本技能原创的默认 IP。圆胖软萌，但做事认真：它总是嵌在结构里干活，不当摆件。外形和小黑、小互角色库都刻意做了区分，对照表见文末。

## 一句话

一只**圆滚滚的小黑猫团**：奶白肚皮，黄绿猫眼，粉腮红，头顶长着**两片小绿芽**。小煤球的**小芽和表情就是它的状态**：
- 想通了，小芽上就开出一朵小黄花；
- 卡住了，小芽就蔫下去；
- 在推进中，小芽就一点点长大。

## 外形锁定(每张都必须一致)

- **身体**：一团**矮胖的圆猫身**，宽比高略大，几乎没有脖子。顶上两只**圆角三角猫耳**，耳内是粉色。
  - **深棕黑粗圆描边**，线条圆润；
  - 身体填**煤球黑(深炭灰)**，左上角一道浅灰弧形高光。
- **肚皮**：下半身一块**奶白色的椭圆肚皮**。
- **头顶**：一根短绿茎，上面**两片嫩绿小芽**(像刚冒头的豆苗)。嫩芽绿是它的第二招牌色。
- **脸**：
  - 两只**黄绿色猫眼**，竖椭圆黑瞳，各带一个白色高光；
  - 一个**粉色小三角鼻**，下面一张浅色 **“ω” 猫嘴**；
  - 两颊各一块**粉色腮红**；
  - 两侧各两根**胡须**。
- **四肢**：肚皮两侧一对**圆圆的小肉垫手**，底部两只**半圆小脚**。没有长手长腿，尾巴可以有但很短。
- **线条**：描边是全图最粗的一支笔，图里其他物件用正常手绘线。

## 状态表情(要和文章此刻的状态一致)

| 状态 | 眼 | 嘴 | 头顶 | 适合 |
|---|---|---|---|---|
| **开心 / 平常** | 黄绿猫眼 + 高光 | ω | 小芽竖起 | 默认、在干活、顺利 |
| **卡住 / 蔫了** | `> <` 两道折线 | 小小的倒 U | **小芽耷拉、发灰绿**，额角一滴蓝色汗珠 | 卡住、失败、被否定、累 |
| **想通 / 开花** | 弯弯的笑眯眼 | 张开的小笑嘴 | 小芽茎拉长，顶端**开出一朵五瓣小黄花** | 顿悟、关键结论、做对了 |
| **犹豫** | 一只猫眼 + 一只眯眼 | 一字嘴 | **一只耳朵折下来**，头顶冒一个小问号 | 拿不准、半懂不懂 |

## 性格

- 软萌、认真，带点猫的小脾气。遇到难事会先蔫一下，然后抱着往前推。
- 一本正经地做一件荒诞的事：把没用的东西一爪推下桌，钻进纸箱当分类框，或者抱着毛线团理线头。
- 很诚实：没想通就不开花，绝不硬装。

## 动作库(小煤球的特权：猫的习性 + 头顶小芽)

| 动作 | 适合表达 |
|---|---|
| **开花**：小芽上冒出小黄花 | 想通、顿悟、关键结论 |
| **蔫**：小芽耷拉、出汗 | 卡住、没思路、失败、透支 |
| **推下桌**：一爪把东西推下桌沿 | 删减、砍掉、放弃、做减法 |
| **钻纸箱**：钻进一个大小正好的纸箱 / 格子 | 归类、装进框架、找到位置 |
| **理毛线**：抱着毛线团，把一团乱线理成一根 | 理清头绪、梳理、连接 |
| **毛线牵连**：用一根毛线把几样东西串起来 | 连接、依赖、对接、打通 |
| **扑**：弓身扑住一个移动的目标 | 抓重点、抓机会、锁定问题 |
| **叼**：叼着一张卡片 / 文件送到下一处 | 传递、交付、搬运 |
| **蹲守**：蹲在洞口 / 屏幕前一动不动 | 监控、等待、观察 |
| **踩奶**：用两只肉垫反复揉一团面 | 打磨、反复迭代 |
| **小芽长大**：同一只小煤球排开，头顶从蔫芽 → 小芽 → 开花 | 进度、阶段、成长、复利 |
| **叠猫塔**：几只小煤球叠成一摞，主角在顶上或在最底下扛着 | 分层、支撑、协作 |

## 嵌入法则

1. **同墨**：小煤球的描边和图里的框、箭头、物件同一种深色笔触。煤球黑填色、奶白肚皮、嫩芽绿只属于它。
2. **当行动者**：小煤球在结构内部干活，比如推、叼、理线、钻箱子，不站在旁边指点。
3. **整合测试**：把小煤球擦掉，它原来的位置应该是结构里的一个洞。如果擦掉后核心隐喻仍完全成立，说明小煤球只是装饰，要重写。
4. **占比**：
   - 解释图约 15-25%；
   - 情绪图可到 20-40%；
   - 人小物大的构图里，它要画得更小。
5. **多只小煤球**：小芽长大和叠猫塔时，画面里可以有 2-6 只，但每只都只是**同一个角色的不同时刻**或明确的“分身”，主角那只要最大、最清楚。

## 可爱的边界

- **要**：圆、软、猫眼、腮红、动作有点憨。读者第一眼会觉得“好可爱”，第二眼看懂它在干什么。
- **不要**：
  - 儿童绘本的厚涂；
  - 贴纸风的白色外描边；
  - 3D 盲盒、高光塑料感；
  - 满屏星星爱心；
  - 卖萌摆拍。可爱是从它认真干活的样子里流露出来的，不是靠摆出来的。

## 禁止

- 画成纯黑无脸的软团，或者只有两个白点眼。那是 Ian 的小黑，不是小煤球。
- 丢掉猫耳、胡须、奶白肚皮或头顶小芽中的任何一个。
- 画成写实黑猫、瘦长猫、有长腿的猫，或者穿衣服、戴帽子。
- 每张都开花。状态必须对应文章此刻的真实情况。
- 只站在角落看。
