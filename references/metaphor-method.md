# 现编隐喻:每张图都为这篇文章重新发明

## 结构类型(选一种,别混)

| 类型 | 适合 | 画法 |
|---|---|---|
| Workflow 流程 | 输入→处理→输出、AI 工作流 | 左输入、中间小黑或怪机器处理、右输出,橙色箭头表主流向 |
| 系统局部 | 信息源、过滤器、数据库、agent 局部 | 只画 3-5 个核心模块,小黑参与其中一个关键动作 |
| 前后对比 | 混乱/有序、手动/自动 | 左乱右稳,中间橙色箭头 |
| 角色状态 | 痛点、卡住到跑起来 | 2-4 个小状态,每个一句短标注 |
| 概念隐喻 | 内容工厂、脑内黑盒 | 一个大怪物件,少量输入,一个输出,要有记忆点 |
| 方法分层 | 框架、能力栈 | 一层层盒子(不要正式金字塔),小黑搬砖或搭建 |
| 地图路线 | 从想法到上线、承接路径 | 一条弯路,少量节点,小黑牵线或走路 |
| 小漫画分镜 | 失败到成功、前后变化 | 2-4 格,每格一个动作 |
| 单点卡死 | 瓶颈、限流、队列积压 | 整个系统卡在一个点,小黑常就是那个堵点 |
| 堆积 / 渗漏 | 上下文涨满、预算烧完 | 东西堆积、溢出、漏光,小黑被淹 / 接漏 / 看着排空 |

## 三步法(核心)

1. **抽象概念 → 一个物理动作**:卡住、漏掉、变重、分拣、沉淀、发酵、开门、折叠、拆包、回流、称重、接住。
2. **系统结构 → 一个低科技物件**:坏机器、纸箱、抽屉、漏斗、秤、邮筒、门、井、梯子、水管、线团、闸门、转盘、黑盒、打孔器、压面机、晾衣绳、怪工位。只选 1-2 个。
3. **让小黑承担动作**:卡在机器里、拉错线、守门、搬运、修补、称重、扶梯子、记录、把东西塞进怪装置。动作池:拉、扛、塞、捞、压、称、缝、剪、拧、守、推、接、拆、标记、回收。

动作要服务核心意思,不要为了怪而怪。

## 动作命名闸

进生成前,把核心动作写成**一个动词短语**:

- ✅ “小黑把三种来源的线拧成一股塞进黑盒”
- ✅ “小黑趴在第二个缺口里用身体接住掉下来的信”
- ❌ “小黑和一个流程图”(没有动作)

写不出 = 还没想清楚画面,别开工。

## 隐喻逐一对照(防比歪)

解释图必填。每个物件 / 动作对应哪个真实部件:

| 隐喻物件 | 真实部件 | 对得上? |
|---|---|---|
| 大而慢的仓库 | 闪存(大、慢) | ✓ |
| 小工作台 | 内存(小、快) | ✓ |

- 物件对不上真实机制(纯为好看)→ 删或换。
- 关键部件没有对应物 → 补,否则图是残的。
- 终判据:外行看图 + 标注,能不能翻译回真实机制?

## 情绪图:演处境 > 演表情

小黑本来就没什么表情,所以情绪全靠**处境**:

- 焦虑 → 小黑小小地埋在一堆消息便利贴里,只露白点眼。
- 被 deadline 追 → 小黑困在沙漏下半截,沙快埋到眼睛。
- 选择困难 → 小黑站在一圈门中间,每扇门都伸出手拽它。

**人小物大**:物件巨大顶天,小黑极小(画幅 1/10-1/6),情绪从尺度对比里出来。

## 一篇一世界(可选)

条件:判“配” ≥3 张,且多数锚点同属一个机制域。为整篇发明一个世界(旧邮局、地下车间、配电房、渡口……),每张 = 世界里不同的认知动作。

逃生口:某个锚点塞进世界会比歪 → 那张退出世界单独编。准确 > 世界感。

## 反复刻规则

不要复刻 Ian 小黑或小互的旧案例构图,除非用户明确说“照这张改”:

- 传送带两个断点、小黑拉判断杆、小黑变漏斗分拣、切素材鱼、牵承接路径、拉三层信息源、三个小黑拿喇叭/搭桥/开门、盖章话术工具箱、举牌看常见坑。

同类主题也换新隐喻:“承接路径”不一定画路线,可以画小黑把内容尾巴接到门把手上;“一鱼多吃”不一定画鱼,可以画小黑把一个纸团压成几种形状。

判据:这个隐喻放在哪篇文章都能用 → 太通用,没榨到这篇的独特点,重编。
