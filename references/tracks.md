# 四种图的画法

## 情绪图(钩子:让读者“想读”)

- 小灯陷进体现情绪的**处境**,不靠表情(小灯无眼无嘴),用亮 / 灭 / 闪、灯丝形状、拔插头、过载冒烟等状态演。
- 首选“人小物大”:巨大物件顶天,小灯极小但灯泡亮度和灯丝形状清楚可见。
- 巨物上贴真实场景标签:未读 99+ / 紧急!! / 又改需求。
- 一张最多一个红色重点。
- 交付判据:先觉得“有点怪”,1 秒内看懂。

## 解释图(让读者“读懂”)

类型与内容槽(每个槽都要能在原文找到出处):

| 类型 | 内容槽 |
|---|---|
| 流程 | 方向 + 3-7 步(步骤名 + 原文动词)+ 卡点 |
| 结构 | 3-8 个部件(名 + 职责)+ 关系 + 核心部件 |
| 对比 | 左项 2-4 点 + 右项 2-4 点 + 分隔 + 结论;**两侧必须共享同一个写死的被对比对象** |
| 阶梯 | 3-6 级,低→高,每级一句 |
| 关系 | 节点 + 每条线代表的关系(触发 / 审 / 调用 / 依赖) |

- 小灯嵌进结构干活(~15-25%),同笔同线。
- 可以有清晰的框和箭头,但手绘、留白、不像课件。
- 代码 / 表格只画骨架(`SELECT … FROM …` + 省略号),标签 ≤3 个,宁可空白牌也不要乱码。
- 交付判据:1 秒看懂机制,每个部件对得上原文。“怪”不是目标,“准 + 直观”是。

## 四格(讲过程 / 转折)

先过硬判据(满足其一):因果是主张 / 步骤累积 / 末格反转 / 同场景节奏重复。
否决:格子可重排或可删一格不丢意义 → 塌回单张;只有两态没有中间旅程 → 用对比图。

- 一张图内 2x2 网格,细格线 + 白色间隔,比例 1:1 或 3:4。
- 起(现状)→ 承(踩坑)→ 转(转机)→ 合(结局);每格一句 ≤8 字标注。
- 同一个小灯贯穿四格,靠处境变化演情绪。

## 篇级总览海报(可选,一篇最多 1 张)

起海报条件:≥3 步完整主流程 / 一组并列对比 / 读者需先看全貌。单个机制不起。

- **先锁结构再排版**:先从原文列出 N 个 panel 的真实内容,再配最小场景。
- 3-6 个 panel,大号编号 01-0N + 3-6 字关键词 + ≤12 字注脚。
- 每个 panel 里小灯小小地干一件事;靠编号和流程线撑版面,不靠角色。
- >6 步或每格要长文字 → 退回散图。
