# 拆解方案输出模板

方案要短而准。用户能在 30 秒内看懂“配哪几张、为什么、小方在干嘛”。不要输出推理过程、不讲风格理论。

## 模板

```markdown
## 配图拆解方案:{文章标题}

**全文主张**:{一句话}
**建议张数**:{N} 张({情绪 a / 解释 b / 四格 c / 总览海报 0-1})
**一篇一世界**:{不启用 / 启用:世界设定一句话}

### 逐节判定
| 小节 | 信号 | 判定 | 理由 |
|---|---|---|---|
| … | … | 配·解释 / 配·情绪 / 配·四格 / 不配 | 一句话 |

### Shot list

#### 01 · {主题}
- **位置**:{第 X 节「…」第 N 段后}
- **核心意思**:{灵魂话}
- **图类型 / 结构**:{解释·流程} / {Workflow}
- **小方在做什么**:{动词短语}
- **隐喻对照**:{物件A → 真实部件A};{物件B → 真实部件B}
- **必现内容**:{原文真值 1};{原文真值 2}
- **建议元素**:{1-2 个物件}
- **中文标注**:{标注1} / {标注2} / {标注3}
- **比例 · 小方占比**:{4:3} · {小·嵌入}

#### 02 · …

### 稳 / 可选
- 最稳:{编号}——{一句理由}
- 可选:{编号}——{一句理由,可删}
```

## 示例(节选)

文章:《内容为什么做了没人接》——讲“内容生产 → 被看见 → 被承接 → 转化”的断点。

```markdown
## 配图拆解方案:内容为什么做了没人接

**全文主张**:内容不是没人看,是看完没地方接。
**建议张数**:4 张(情绪 1 / 解释 2 / 四格 1)
**一篇一世界**:启用——一间漏水的旧邮局,内容是信,读者是收件人。

### 逐节判定
| 小节 | 信号 | 判定 | 理由 |
|---|---|---|---|
| 开头吐槽 | 情绪 | 配·情绪 | 需要钩子,让读者代入“发了没回响” |
| 两个断点 | 流程 | 配·解释 | 断在哪两处,文字要数着记 |
| 我的承接清单 | 列举 | 不配 | 清单本身已清楚 |
| 三个月变化 | 时间线 | 配·四格 | 有起承转合 |
| 承接路径 | 结构 | 配·解释 | 路径节点抽象 |

### Shot list

#### 01 · 发了没回响
- **位置**:开头吐槽段后
- **核心意思**:写得很用力,掉进的是空邮筒
- **图类型 / 结构**:情绪 / 概念隐喻
- **小方在做什么**:小方把一封封信塞进一个底部漏空的邮筒
- **建议元素**:漏底邮筒、地上散落的信
- **中文标注**:已发出 / 没人收 / 又一封
- **比例 · 小方占比**:1:1 · 中(30%,理由:钩子图要让读者代入)

#### 02 · 两个断点
- **位置**:「两个断点」节末
- **核心意思**:不是没人看,是看完和信任之间断了两次
- **图类型 / 结构**:解释·流程 / Workflow
- **小方在做什么**:小方蹲在分拣台第二个缺口里,张开盒盖把掉下的信接住
- **隐喻对照**:分拣台 → 内容分发;第一个缺口 → 看完无下一步;第二个缺口 → 有兴趣但没信任凭证
- **必现内容**:曝光 → 阅读 → 承接 → 信任 → 转化(五段,断在承接与信任)
- **建议元素**:分拣台、两个缺口
- **中文标注**:看完了 / 然后呢 / 断点① / 断点②
- **比例 · 小方占比**:4:3 · 小·嵌入
```
