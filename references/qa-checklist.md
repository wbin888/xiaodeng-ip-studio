# QA Checklist

## 先查选点(最重要)

- 遮住标注问“这图在讲啥”,答案是不是本节真正的修辞任务?不是 → 回 `analysis-playbook.md` 重锁点再生成,别只调画面。

## 必过项

- 比例符合方案,方向词一致,没被模型改成方图。
- 纯白背景,无纸纹、阴影、渐变、米色、噪点。
- 有小煤球,且小煤球承担核心动作(整合测试:擦掉小煤球,原位置是结构里的一个洞)。
- 小煤球没有多余肢体,背景线不穿过身体,每只肉垫手最多拿一个道具。
- 小煤球外形锁定:圆胖黑猫团 + 两只圆角猫耳 + 奶白肚皮 + 头顶两片绿芽;黄绿猫眼带高光、粉三角鼻、ω 嘴、粉腮红、左右胡须;圆肉垫手、半圆小脚;煤球黑 / 奶白 / 嫩芽绿只在它身上;开心 / 蔫 / 开花 / 犹豫与这一刻的文章状态一致。
- 一张图只讲一个核心结构;主体 ≤60%,留白 ≥35%。
- 隐喻是为这篇现编的,没复刻旧案例。
- 解释图:Q4 必现内容逐条都在且正确,数量对;隐喻对照表对得上。
- 对比图:左右两侧是同一个被对比对象。
- 中文标注少、短、无错字;没有色值 / 色名 / 结构类型被画成字。
- 颜色语义正确:橙 = 主路径,红 = 重点 / 问题,蓝 = 补充。
- 全篇视觉契约一致;相邻两张在隐喻物件、构图、小煤球动作、标注位置中至少 3 项不同。
- 整组分布:情绪图不超过一半;该有解释图 / 四格的没有被情绪图替代。

## 多 IP 加查(启用演员表时)

- 每个同框 IP 都过整合测试:擦掉任意一个,结构里都会少一块;没人在旁边围观。
- 角色之间没有合体、没有串色:每个 IP 只有自己的招牌色,外形和 `cast-roster.md` / 角色包的 QA 外形锁定一致。
- 小互角色已经转成白底黑线稿 + 淡主色,不是 3D 盲盒或厚涂。
- 单张最多 2 个 IP;出现 3 个时,这张必须是总览 / 四格 / 交接图。IP 合计占比 ≤35%(情绪图主角除外)。
- 全篇看:每个角色的「代表」没有中途换;主角出场 ≥50%,每个搭档至少出场 1 次。

## 失败信号

- 左上角出现“常见坑 / Workflow / 系统架构图 / 路线图”等标题。
- 小煤球太幼稚、贴纸化、卖萌摆拍,或只站在旁边看。
- 小煤球被画成无脸黑团或白点眼(像小黑),丢了猫耳 / 胡须 / 肚皮 / 小芽,画成写实猫 / 长腿猫,或 3D / 贴纸风,直接重生成。
- 画面像 PPT、课件、正式流程图;元素、箭头、节点太多。
- 文字变成大段解释,或中文错字严重。
- 画面死板,没有荒诞隐喻。
- 很漂亮但画错了重点或机制。

## 迭代修法

| 症状 | 修法 |
|---|---|
| 太普通 | 让小煤球成为动作主体,加一个奇怪但成立的隐喻 |
| 太复杂 | 删节点,只留一个动作 + 3-5 个短标注 |
| 太幼稚 / 贴纸化 / 卖萌摆拍 | 强调 earnest, focused on its job、NOT a children's sticker、no white sticker border、NOT 3D、no posing for the camera;让它回到结构里干活 |
| 太 PPT | 去标题、边框、整齐网格和多余箭头,改成手绘场景 |
| 太像旧案例 | 保留核心意思,换掉主物件和小煤球动作 |
| 文字错 | 少量错字局部编辑;错得多就减少标注重生成。不用 PS / 代码涂改文字 |
| 机制画错 / 对比散架 / 小煤球画崩 | 直接重生成,不带瑕疵交付 |
| 方图 / 比例跑偏 | 重生成 |

## 交付判断

- 情绪图:先觉得“有点怪”,1 秒内看懂。
- 解释图:1 秒看懂机制,每个部件对得上原文。

第一眼像教程页,而不是白纸上的怪诞产品草图 → 不合格。
