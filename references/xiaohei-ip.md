# 小黑 IP

> 小黑是 Ian 小黑配图的视觉语言(来源:helloianneo/ian-xiaohei-illustrations,MIT)。本技能默认由小黑出演,并沿用其署名要求,见 `NOTICE.md`。

## 角色定义

小黑不是吉祥物、不是贴纸,而是正在认真参与系统运转的荒诞工作者。默认每张图都有小黑。

## 外形

- 黑色实心小怪物,白色圆点眼睛。
- 细腿,偶尔有细胳膊(需要操作时伸出,不需要时可没有)。
- 身体可变:圆柱、黑豆、黑盒、漏斗、影子、洞口、机器内部的黑块。
- 轮廓略不规则,有手绘感。
- 表情空、呆、冷静、认真。

## 性格

- 很认真,但做的事有点荒诞。
- 像低调的系统操作员,冷幽默,不卖萌。
- 有点笨拙,但不蠢。

## 嵌入法则(融合小互“同墨嵌入”)

1. **同墨**:小黑和图里的框、箭头、物件用同一支笔,天然不抢戏。
2. **当行动者**:小黑在结构内部干活(卡在断点里、坐进框里、手伸进装置),不站旁边指点。
3. **整合测试**:把小黑擦掉,它的位置应该是结构里的一个洞;如果擦掉后核心隐喻仍完全成立 → 小黑太装饰,重写。
4. **占比**:解释图 ~15-25%;情绪图可到 20-40%(人小物大时更小)。

## 身体可变是小黑的特权

小黑没有固定身体,可以**变成**结构的一部分:

- 变成漏斗、塞子、闸门、秤砣、桥墩、电线里的黑块。
- 适合“单点卡死”“瓶颈”“承重”类锚点。

## 禁止

- 过度可爱的吉祥物、儿童卡通。
- 复杂服装、表情包、闪亮大眼睛。
- 只站在角落看。
- 抢走结构表达。
- 太商业、太圆润、太精致。

## 多个小黑

需要多个行动者时可以有 2-3 个小黑,但每个都在干活,且全图小黑总占比不超过 30%。
