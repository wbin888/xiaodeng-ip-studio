# 小墨 IP

> 本技能内置换角 IP(原创)。气质继承“认真做荒诞事、不卖萌、嵌进结构干活”的方法,外形与小黑等既有 IP 刻意区分(见文末对照)。

## 一句话

一滴**空心描边、内里淡靛蓝晕染**的墨水:**顶端尖角卷成一个小钩,两道竖线眼,没有腿**。它是系统里的流动介质——会流、会分裂、会晕开、会凝固,哪里有变化和扩散,它就在哪里。

## 外形锁定(每张都必须一致)

- **身体**:一滴水滴形墨滴,底部圆、顶部收尖;黑色细手绘轮廓,轮廓略抖。
- **颜色**:内部是**淡靛蓝水彩晕染**(半透明、边缘深中间浅),**不是实心黑、不是实心蓝**。这是小墨唯一的招牌色。
- **尖角**:顶端的尖向一侧**卷成一个小钩**(像毛笔收笔),是第二个识别点。
- **眼睛**:身体中下部**两道短竖线眼**(像“| |”),黑色。没有嘴、没有眉毛、没有白点眼、没有腮红。
- **没有腿**:底部贴地,靠滑行移动;移动时身后拖一道淡淡的靛蓝墨迹。
- **手**:需要时从两侧伸出一根细墨丝当手,最多两根;不需要时不画。
- **线条**:与画面其他物件同一支笔、同样粗细。

## 性格

- 安静、认真、随形就势——给它什么容器,它就变成什么形状,但从不变成别的东西。
- 冷幽默:一本正经地把自己摊成一张地图、拉成一根线、裂成一排小点。
- 有底线:被拉得太薄会断丝,被晒太久会干裂。

## 动作库(小墨的特权:形态变化)

| 动作 | 适合表达 |
|---|---|
| **流**:沿着沟槽 / 管道 / 路线滑过去,身后留墨迹 | 流程、路径、传递、留痕 |
| **分裂**:一滴裂成几滴小墨,各自去不同地方 | 拆分、分发、一鱼多吃、并行 |
| **合流**:几滴小墨汇成一大滴 | 汇总、整合、收敛 |
| **晕开**:落在纸上一圈圈扩散 | 影响力、传播、扩散、渗透 |
| **渗入**:钻进裂缝 / 纸纤维 / 格子里 | 深入、打通、填补缺口 |
| **填形**:倒进容器,变成容器的形状 | 适配、标准化、被框住 |
| **凝固**:变硬成一块方墨锭 / 印章 | 沉淀、定稿、固化、规则化 |
| **拉丝**:被两头扯成细丝,快断了 | 过载、拉扯、资源摊薄 |
| **干涸**:缩小、表面龟裂 | 枯竭、停更、没反馈、耗尽 |
| **滴落**:从高处一滴滴落下 | 节奏、积累、点滴进展 |

## 嵌入法则

1. **同墨**:小墨的轮廓与图中框、箭头、物件用同一支笔,只有身体里那层淡靛蓝是它的。
2. **当行动者**:小墨在结构内部干活(流过管道、渗进缺口、凝成印章),不站旁边指点。
3. **整合测试**:把小墨擦掉,它的位置应该是结构里的一个洞;擦掉后核心隐喻仍完全成立 → 小墨太装饰,重写。
4. **占比**:解释图 ~15-25%;情绪图可到 20-40%(人小物大时更小)。
5. **多个小墨**:分裂出的小墨可以有 2-5 滴,但必须是同一个形象缩小版,全图总占比 ≤30%。

## 禁止

- 画成可爱吉祥物、水滴宝宝、儿童卡通、表情包。
- **实心黑色**身体、白点眼(会和小黑撞脸)。
- 实心饱和蓝、渐变 3D、高光反光、玻璃质感。
- 加腿、加脚、加嘴、加腮红、圆点眼。
- 尖角不卷、尖角朝下,或画成泪滴 emoji。
- 身体变形成别的东西(机器、人形);要表达新东西,用凝固 / 填形 / 外部道具。
- 只待在角落看。
