# 小方 IP

> 本技能内置换角 IP(原创)。气质继承“认真做荒诞事、不卖萌、嵌进结构干活”的方法,外形与小黑、小盒及小互的“方方”(藏青实心方块、两点眼、平嘴)刻意区分(见文末对照)。

## 一句话

一个白色方形纸盒怪:**一只大圆眼、一根天线、一个能掀开的盒盖**。它是系统里沉默的收件员 / 打包员——把东西吞进去、封起来、分装好、再吐出来。

## 外形锁定(每张都必须一致)

- **身体**:接近正方体的白色纸盒,内部留白不填色;黑色细手绘线,轮廓略歪,不是尺子画的立方体。
- **视角**:**正面平视**,正面是一个方框,顶部只露出一条窄窄的盒盖边;不画 3/4 侧视。
- **眼睛**:正面中上部**一只大圆眼**(约正面宽度的 1/3),白眼白 + 黑色实心瞳孔。没有嘴、没有眉毛、没有第二只眼。
- **天线**:盒盖**左上角**伸出**一根**细细的弯天线,顶端一个**蓝色实心小圆点**。这是小方唯一的招牌色。
- **盒盖**:后侧铰链,可以向上掀开成“嘴”。合上时是一条平线,打开时露出黑色的盒内空间。
- **腿**:两根短细腿,无脚掌。
- **手**:需要时从左右两侧各伸出一根细线手臂,最多两只;不需要时不画。
- **线条**:与画面其他物件同一支笔、同样粗细。

## 性格

- 认真、沉默、一丝不苟,像一个只会按规矩办事的仓库员。
- 冷幽默:一本正经地把荒诞的东西装箱、贴签、寄出。
- 有点死板:装不下也要硬塞,卡住了天线会耷拉。

## 动作库(小方的特权:盒盖和天线)

| 动作 | 适合表达 |
|---|---|
| **吞**:掀开盒盖把东西吃进去 | 输入、收集、吸收信息 |
| **吐**:盒盖弹开吐出整理好的东西 | 输出、产出、交付 |
| **封**:合上盖子压住,上面贴一张签 | 沉淀、归档、封存、定稿 |
| **分装**:把一堆东西分进几个小盒 | 分流、拆分、分类 |
| **撑爆**:塞太多,盖子合不上、侧面鼓起 | 过载、上下文涨满、信息焦虑 |
| **卡住**:被卡在管道 / 闸口中间 | 瓶颈、断点、单点卡死 |
| **叠**:几个小方叠成台阶 / 墙 / 桥 | 分层、能力栈、搭建 |
| **天线收信号**:天线弯向某处,蓝点闪 | 感知、判断、接收反馈 |
| **天线耷拉**:天线弯下来 | 卡住、失败、没信号 |

## 嵌入法则

1. **同墨**:小方与图中框、箭头、物件用同一支笔,天然不抢戏。
2. **当行动者**:小方在结构内部干活(吞进输入、卡在断点、封住结果),不站旁边指点。
3. **整合测试**:把小方擦掉,它的位置应该是结构里的一个洞;擦掉后核心隐喻仍完全成立 → 小方太装饰,重写。
4. **占比**:解释图 ~15-25%;情绪图可到 20-40%(人小物大时更小)。
5. **多个小方**:最多 2-3 个,都在干活,全图总占比 ≤30%。可以有大小不同的小方表示层级。

## 禁止

- 画成可爱吉祥物、儿童卡通、表情包。
- 两只眼、加嘴、加腮红、加表情符号。
- 牛皮纸色、米色、带纹理的纸箱;写实快递箱;3D 渲染。
- 3/4 侧视的立体纸盒;盒子上贴胶带。
- 天线超过一根,或天线顶端不是蓝点。
- 把身体拉长成机器、桥、管道(要变形就用多个小方或外部道具)。
- 只站在角落看。
