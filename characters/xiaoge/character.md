# 小格 IP

> 本技能内置换角 IP(原创)。气质继承“认真做荒诞事、不卖萌、嵌进结构干活”的方法,外形与小黑及小互角色库(尤其是黄色便利贴“贴贴”)刻意区分(见文末对照)。

## 一句话

一张**从笔记本上撕下来的方格纸**:**白底淡蓝方格、顶边撕口锯齿、右下折角、一只大圆眼**。它是系统里的“一条记录”——被写下、贴上、撕下、折起、摞高。

## 外形锁定(每张都必须一致)

- **身体**:接近正方形的**白色方格纸**,黑色细手绘轮廓;纸面印**淡蓝方格线**。
- **顶边**:**锯齿撕口**(从线圈本上撕下来的痕迹),这是第一识别点。
- **折角**:右下角向内折起一个小三角。
- **眼睛**:正面中上部**一只大圆眼**,白眼白 + 黑瞳孔。没有嘴、没有眉毛、没有第二只眼。
- **腿**:两条细腿;需要时两侧伸出细线手,最多两只。
- **颜色**:淡蓝方格是小格唯一的招牌色;**不是黄色便利贴、身上不贴小纸条**。
- **线条**:与画面其他物件同一支笔、同样粗细。

## 性格

- 认真、规整、有点强迫症:什么都想对齐到格子上。
- 冷幽默:一本正经地把自己折成表格、纸飞机、收纳盒。
- 记性好,但纸很薄:被写太满会透、被揉过会皱。

## 动作库(小格的特权:纸的形态)

| 动作 | 适合表达 |
|---|---|
| **记**:身上方格被一格格填满字 / 勾 | 记录、打卡、进度、清单 |
| **贴**:被图钉钉到墙上 / 看板上 | 钉住重点、标记、公示 |
| **撕**:从线圈本上撕下来 | 拆出一条、单独拎出、离开体系 |
| **折**:折成纸飞机 / 小盒 / 箭头 | 转化、发出、输出、变形 |
| **叠**:很多张方格纸越摞越高,小格在最上面 | 积累、堆积、待办过载 |
| **对齐**:把乱放的东西摆进自己的格子 | 结构化、归类、标准化 |
| **写满透墨**:格子写满,背面都透了 | 信息过载、塞太多 |
| **揉皱**:被揉成团又摊开,满身折痕 | 被否定、返工、重来 |

## 嵌入法则

1. **同笔**:小格轮廓与图中框、箭头、物件同一支笔,只有方格线是淡蓝。
2. **当行动者**:小格在结构里当一条记录 / 一个格子(被填写、被钉住、被折起),不站旁边指点。
3. **整合测试**:擦掉小格,结构里应该少一张关键的纸;擦掉后核心隐喻仍完全成立 → 太装饰,重写。
4. **占比**:解释图 ~15-25%;情绪图可到 20-40%。
5. **多张纸**:摞起来时其他纸是普通方格纸(无眼无腿),只有小格是角色。

## 禁止

- 画成可爱吉祥物、儿童卡通、表情包;两只眼、加嘴、加腮红。
- **黄色便利贴、身上贴满小纸条**(会和小互的“贴贴”撞脸)。
- 横线本 / 白纸 / 牛皮纸;3D 纸张质感、阴影。
- 顶边画成平直边;折角消失。
- 只站在角落看。
