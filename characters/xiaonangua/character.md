# 小南瓜 IP

> 本技能原创的内置换角。软萌圆胖，做事认真：嵌在结构里干活，不当摆件。适合成长、积累、季节、收获类文章。用 `--cast 小南瓜` 启用。

## 一句话

一只**圆胖的粉彩橙小南瓜**：深棕粗圆描边，豆豆眼，大腮红，头顶**两片小绿芽**。想通了小芽开花，卡住了小芽蔫掉，推进中就顺着藤蔓一颗颗结果。

## 外形锁定(每张都必须一致)

- **身体**：矮胖圆南瓜，宽比高大，顶部中间微微凹进去；瓜身两条浅橙弧形瓜棱，底部一道奶白高光。
- **颜色**：瓜身**粉彩南瓜橙**(柔和、不刺眼)，**不是鲜橙实心色**，与画面里的橙色流程箭头区分开。
- **描边**：**深棕色粗圆描边**，是全图最粗的一支笔。
- **头顶**：一根短绿茎 + **两片嫩绿小芽**。
- **脸**：两颗深棕**豆豆眼**，一张小 **“ω” 嘴**，两颊各一块**大粉腮红**。没有眉毛和鼻子。
- **四肢**：身体两侧一对**小弧线手**(贴在腮红下方)，底部两只**半圆小脚**。

## 状态表情

| 状态 | 眼 | 嘴 | 头顶 | 适合 |
|---|---|---|---|---|
| **开心 / 平常** | 豆豆眼 | ω | 小芽竖起 | 默认、顺利 |
| **卡住 / 蔫了** | `> <` | 倒 U | 小芽耷拉发灰绿 + 蓝汗珠 | 卡住、失败、累 |
| **想通 / 开花** | 弯弯笑眯眼 | 张嘴笑 | 小芽上**开出五瓣小黄花** | 顿悟、关键结论 |
| **犹豫** | 一只豆豆眼 + 一只一字眼 | 一字嘴 | 小芽歪向一边 + 小问号 | 拿不准 |

## 性格

软萌、认真、有点憨。一本正经地做荒诞事：拉着藤蔓当绳子用，滚下坡撞开卡住的门，掀开顶盖往里装点子。没想通就不开花。

## 动作库(藤蔓、果实、顶盖、滚动)

| 动作 | 适合表达 |
|---|---|
| **开花** | 想通、顿悟 |
| **蔫** | 卡住、失败、透支 |
| **藤蔓牵连**：头顶拉出藤蔓缠住别的东西 | 连接、依赖、打通 |
| **结果进度**：藤上一串南瓜从青 → 半熟 → 熟 | 进度、阶段、成长 |
| **滚**：缩成一团滚过关卡 | 推进、加速、冲过障碍 |
| **顶 / 推**：用圆肚子顶开门 | 克服阻力 |
| **开盖 / 撒种子**：掀起顶盖装东西或撒出瓜子长新苗 | 收集、产出、复用 |
| **叠罗汉** | 分层、支撑、协作 |

## 嵌入法则

1. 小南瓜在结构内部干活，不站在旁边指点；擦掉它，原位置应是结构里的一个洞。
2. 占比：解释图约 15-25%，情绪图可到 20-40%。
3. 结果进度、叠罗汉里可有多只南瓜，但**只有一只有脸和手脚**，其余是普通南瓜。

## 禁止

- 画成万圣节南瓜灯(三角眼、锯齿嘴、里面点蜡烛)。
- 鲜橙实心色、和流程箭头混成一片。
- 长手长腿、穿衣戴帽、3D 盲盒、贴纸白边。
- 每张都开花。
